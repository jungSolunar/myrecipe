기본 상태 — 삭제 확인 모달

레시피 카드/상세 화면의 “삭제” 버튼을 누르면 배경을 딤 처리하고 이 다이얼로그를 띄운다. 포커스는 다이얼로그 내부에 트랩되며 기본 포커스는 취소 버튼에 둔다.

레시피를 삭제할까요?

“기본 계란말이” 레시피가 목록에서 영구 삭제됩니다. 이 작업은 되돌릴 수 없습니다.

상태 A — 삭제 중 (loading)

레시피를 삭제할까요?

“기본 계란말이” 레시피가 목록에서 영구 삭제됩니다. 이 작업은 되돌릴 수 없습니다.

상태 B — 삭제 완료 → 목록으로 (toast)
“기본 계란말이”를 삭제했습니다. 레시피 목록으로 이동합니다.
상태 C — 권한 없음 (US-007 AC2)
본인이 등록한 레시피만 삭제할 수 있습니다. (서버 403) 비로그인은 로그인 게이트로 유도.
참고 — 반응형/구현
모바일에서는 하단 시트(bottom-sheet) 변형 허용. 배경 스크롤 잠금, ESC/취소로 닫힘, 삭제 버튼은 danger 색으로 명확히 구분. 포커스는 다이얼로그 내부 트랩.
