# Recipe Box — 레시피 & 식재료 관리 웹서비스

개인이 자신의 레시피와 보유 식재료를 한 곳에서 등록·검색·관리하고, 보유 재료 기준으로
레시피를 활용할 수 있게 하는 웹 서비스입니다. (여러 일반 회원 / 열람 자유, 등록·수정은 로그인 / PC·모바일 반응형)

- **현재 릴리스**: [v1.0.0](docs/releases/v1.0.0.md) — 1차 출시 (Must US-001~010)
- 기획 문서: [PRD](docs/prd.md) · [백로그](docs/backlog.md) · [진행 상태](docs/project-status.md)
- 실행/개발: [프론트엔드](web/README.md) · [배포·롤백 런북](deploy/README.md)

## v1.0.0 — 1차 출시 (✅ 출시됨)

레시피와 식재료를 등록·관리·검색하는 기반 기능(Must). 상세 수용 기준은 [PRD 4절](docs/prd.md) 참조.

| ID | 기능 | 설명 |
|---|---|---|
| US-001 | 회원가입 | 이메일/비밀번호 가입 (bcrypt 해시) |
| US-002 | 로그인 / 로그아웃 | 세션 쿠키(HttpOnly) 인증 |
| US-003 | 비로그인 열람 · 게이트 | 열람은 자유, 등록·수정·삭제는 로그인 필요 |
| US-004 | 레시피 등록 | 제목·조리 단계·카테고리·재료, 이미지 업로드(선택) |
| US-005 | 레시피 목록 · 상세 | 페이지네이션 목록 + 상세 조회 |
| US-006 | 레시피 수정 | 소유자만 수정 |
| US-007 | 레시피 삭제 | soft delete |
| US-008 | 식재료 마스터 | 회원 개인별 식재료(이름·분류·단위) 관리 |
| US-009 | 레시피-식재료 연결 | 마스터에서 재료를 선택해 수량과 함께 연결 |
| US-010 | 레시피 검색 · 필터 | 이름·카테고리·재료 기준 검색·필터 |

**알려진 제한**: 재고 관리·부족 재료 표시·추천 미포함(로드맵), 단위 자동 환산 미지원,
전용 헬스체크 엔드포인트 없음(`GET /openapi.json`로 대체), SQLite 동시성 제약(소규모 전제).
전체 내용은 [릴리스 노트](docs/releases/v1.0.0.md) 참조.

## 기술 스택

- **프론트엔드**: React 18 + TypeScript + Vite (정적 SPA, MSW 데모 목 포함) — [`web/`](web/)
- **백엔드**: Python + FastAPI (ASGI, uvicorn/gunicorn), SQLite — [`server/`](server/)
- **인증**: 세션 쿠키(HttpOnly, 운영 시 Secure)
- **API**: `/api/v1` 프리픽스, 표준 에러 포맷 `{error:{code,message,details}}` — 계약: [`api/openapi.yaml`](api/openapi.yaml)

## 빠른 시작 (개발)

```bash
# 프론트엔드 (백엔드 없이 MSW 목으로 전 화면 데모 가능)
cd web && npm install && npm run dev     # http://localhost:5173
# 데모 시드 계정: chef@example.com / password1
```

실제 백엔드 연결 및 배포·롤백 절차는 [배포 런북](deploy/README.md)을 참조하세요.
