# 화면 가이드 (Screen Guide)

기준 버전: **v1.2.0** · 갱신일: **2026-07-25**

"어떤 기능이 어느 화면에서 어떻게 동작하는가"를 **화면 기준**으로 정리한 기획문서다.
릴리스 노트(무엇이 바뀌었나)·user-flows(흐름도)와 달리, 사용자·팀원이 화면에서 기능 위치를 찾는 참조용이다.
근거: 실제 라우트(`web/src/App.tsx`), 화면 컴포넌트, `docs/releases/*`, `docs/prd.md`.

## 화면 지도 (IA)

| 경로 | 화면 | 접근 권한 | 진입점 |
|---|---|---|---|
| `/` | 레시피 목록 | 열람 자유 | 브랜드 로고 "🥕 레시피 상자", 앱 기본 진입 |
| `/recipes/:id` | 레시피 상세 | 열람 자유 | 목록 카드 클릭 |
| `/recipes/new` | 레시피 등록 | 로그인 필요 | 목록 "+ 새 레시피" |
| `/recipes/:id/edit` | 레시피 수정 | **본인만** | 상세 "수정" |
| `/ingredients` | 식재료 마스터 | 로그인 필요 | 헤더 "식재료 마스터" |
| `/inventory` | 내 재고 | 로그인 필요 | 헤더 "내 재고" |
| `/login` | 로그인 | 비로그인 | 헤더 "로그인" 버튼, 게이트 유도 |
| `/signup` | 회원가입 | 비로그인 | 로그인 화면 "계정 없음" |

> 비로그인은 목록·상세만 열람 가능. 등록·수정·삭제·재고·마스터 진입 시 로그인 게이트로 유도되고
> 로그인 후 원래 화면으로 복귀(`returnTo`). (US-003)

## 화면별 상세

### 레시피 목록 (`/`)
- **접근 권한**: 열람 자유(비로그인 포함)
- **진입점**: 앱 기본 화면, 헤더 브랜드 로고

| 동작 | 화면 위치 | 방식 | 조건/예외 | US | 도입 |
|---|---|---|---|---|---|
| 레시피 열람 | 카드 그리드 | 카드 클릭 → 상세 | — | US-005 | v1.0.0 |
| 검색 | 검색·필터 바 | 검색어 입력 | — | US-010 | v1.0.0 |
| 카테고리·재료 필터 | 검색·필터 바 셀렉트 | 선택 시 즉시 적용, 칩으로 표시 | 재료 옵션은 로그인 회원만(개인 마스터) | US-010 | v1.0.0 |
| 새 레시피 | 상단 "+ 새 레시피" | 등록 화면 이동 | 비로그인 시 로그인 게이트 | US-004 | v1.0.0 |
| **보유 재료 추천 필터** | **검색·필터 바의 "만들 수 있는 레시피만" 토글** | ON 시 재고와 대조해 **부족 0 레시피만** 노출 + **부족 적은 순** 정렬. 카운트가 "만들 수 있는 레시피 N건 · 부족 적은 순"으로 표시 | **비로그인**→🔒 로그인 안내로 비활성 / **재고 0건**→재고 등록 안내로 비활성 | US-013 | **v1.2.0** |
| **부족 재료 배지(카드)** | 추천 모드 시 각 카드 | 모든 재료 보유=✓ / 부족 시 "부족 N개" | 추천 토글 ON일 때만 | US-013 | **v1.2.0** |
| 추천 결과 안내 배너 | 목록 상단 | 모두 충족→"지금 바로 만들 수 있는…", 근접만→"재료 1~2개만 더…" | 추천 모드 & 결과 있을 때 | US-013 | v1.2.0 |
| 추천 결과 없음(Empty) | 목록 영역 | "보유 재료로 만들 수 있는 레시피가 아직 없어요" + [필터 끄기]·[재고 등록] | 추천 모드 & 결과 0건 | US-013 | v1.2.0 |

> **보유 재료 추천을 확인하는 곳**: 레시피 목록(`/`) 검색·필터 바의 **"만들 수 있는 레시피만"** 토글.
> 로그인 + 재고 1건 이상일 때 활성화되며, 켜면 내 재고로 부족 없이 만들 수 있는 레시피만 부족 적은 순으로 보여준다.
> (별도 "추천" 메뉴/화면이 아니라 기존 목록 화면의 필터로 제공 — PRD 의도)

### 레시피 상세 (`/recipes/:id`)
- **접근 권한**: 열람 자유

| 동작 | 화면 위치 | 방식 | 조건/예외 | US | 도입 |
|---|---|---|---|---|---|
| 레시피 내용 열람 | 본문(제목·재료·조리 단계·사진) | — | — | US-005 | v1.0.0 |
| **재료별 보유/부족 배지** | 재료 목록 각 항목 | 재고 대조 결과 "✓ 보유" / "부족" | 로그인 & 재고 데이터 있을 때 활성 | US-012 | v1.1.0(활성) |
| 수정 | "수정" 버튼 | 수정 화면 이동 | **본인만** 노출·허용 | US-006 | v1.0.0 |
| 삭제 | "삭제" 버튼 | 삭제 확인 → 삭제 후 목록 복귀 | 본인만 | US-007 | v1.0.0 |

### 레시피 등록 / 수정 (`/recipes/new`, `/recipes/:id/edit`)
- **접근 권한**: 등록=로그인 필요, 수정=본인만

| 동작 | 화면 위치 | 방식 | 조건/예외 | US | 도입 |
|---|---|---|---|---|---|
| 제목·조리 단계·사진 입력 | 폼 | 저장 시 상세로 이동 | 제목 필수(미입력 시 인라인 오류) | US-004 | v1.0.0 |
| 재료 연결 | 재료 피커 | 식재료 마스터에서 검색·선택 + 수량 | 마스터에 없으면 새 재료 생성 후 연결 | US-009 | v1.0.0 |

### 식재료 마스터 (`/ingredients`)
- **접근 권한**: 로그인 필요 · **진입점**: 헤더 "식재료 마스터"
- **주요 동작**: 개인 식재료 마스터 등록·수정·삭제(회원 개인별). 레시피 재료 연결과 재고의 기준 목록. (US-008)

### 내 재고 (`/inventory`)
- **접근 권한**: 로그인 필요 · **진입점**: 헤더 "내 재고"

| 동작 | 화면 위치 | 방식 | 조건/예외 | US | 도입 |
|---|---|---|---|---|---|
| 보유 재고 목록 | 재고 테이블 | 재료명·보유 수량·유효기간 배지 | — | US-011 | v1.1.0 |
| 재고 추가 | 상단 추가 폼 | 마스터 재료 선택 + 수량 등록 | 로그인 필요 | US-011 | v1.1.0 |
| 소진 처리 | 행별 삭제 | 보유 목록에서 제거(마스터는 유지) | — | US-011 | v1.1.0 |

> 여기 등록된 재고가 레시피 상세의 보유/부족 배지(US-012)와 목록의 추천 필터(US-013)의 판정 기준이 된다.

### 로그인 / 회원가입 (`/login`, `/signup`)
- **접근 권한**: 비로그인
- **주요 동작**: 이메일/비밀번호 회원가입(중복·형식 검증, 성공 시 자동 로그인) 및 로그인/로그아웃.
  게이트로 유도된 경우 로그인 성공 후 원래 화면으로 복귀. (US-001, US-002, US-003)

## 알려진 제한 (화면 동작 관련)
- 추천/부족 판정은 **동일 단위 기준**만 대조(g↔개 등 환산 미지원).
- 개발용 MSW 목에는 `/inventory`·추천 계산이 없어 **실제 백엔드 연결 시에만** 추천 토글이 동작한다.
- 추천 정렬(`missing_asc`)은 소규모 데이터 전제.
